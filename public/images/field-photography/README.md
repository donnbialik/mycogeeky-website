# MycoView field photography

This folder holds original field photographs being considered for MycoView editorial pages, research stories, and community features.

## Uploading

Upload JPG, PNG, or WebP photographs here on the `content/field-photography-library` branch. Use descriptive lowercase hyphenated filenames (for example `forest-documentation-overhead-01.jpg`). Avoid including private location data in filenames. Do not upload screenshots of the phone photo viewer when the original image is available.

Images in this folder are candidates, not automatically published or placed on the site. Before publishing photographs of identifiable people, particularly children, confirm appropriate permission. Remove sensitive GPS metadata if needed.

## Organization

For now keep new candidates in this single folder. We can add categories and a photo manifest after reviewing the collection, without creating unnecessary nested folders up front.
