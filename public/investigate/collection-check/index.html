Collection Check

Find fungi records that stalled partway between the woods and GenBank, from the observation fields on someone’s public iNaturalist observations.

iNaturalist checking… New here?
  1. 1Whose records: an iNaturalist username, and optionally a date
  2. 2Check the fields: confirm which observation fields mean voucher, plate, sequence or GenBank
  3. 3See the gaps: each check lists the records it caught, with links
  4. 4Export: download the list as a spreadsheet to work through

1Whose records?

Reads fungi observations (including lichens) one page of 200 at a time, about one request a second as iNaturalist asks. Nothing is written to iNaturalist.

2Fields found

Observation fields are named freely, so they’re recognised by name. Untick any that don’t mean what the label says, or add one the tool missed.
