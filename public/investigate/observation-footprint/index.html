Observation Footprint

Where your iNaturalist observations went: into GBIF for researchers, into DNA databases, into named species, into projects and surveys, and into other people’s identifications.

1Whose observations?

Reads public data from iNaturalist and GBIF, a request about every second. Nothing is written anywhere, and nothing about you is stored except the username in this browser.

Provisional names that now have a species name

Records you gave a provisional name whose iNaturalist identification is now a described species. Worth a look: sometimes it means the species was described, sometimes only that the provisional was matched to an existing name.

What this can’t show: which studies used your observations. GBIF counts papers that cite the iNaturalist dataset as a whole, but it can’t say which individual records a paper used, so no tool can list “papers that used your observations” yet. Project counts only cover projects you’ve joined.
