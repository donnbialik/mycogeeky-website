Sequencing Plate Tagger

Load the 96-well plate CSVs you send for sequencing, and write each observation's plate into an iNaturalist observation field. Later, any observation tells you which plate, and so which stored bag, holds its specimen.

1Load plate CSVs

Drop one or more plate .csv files here, or click to choose
Plate label written to iNat: Read from each file name, e.g. a Mycota Lab export named plate-1253-Your Name 2026 #1.csv. You can still edit any plate by hand below. Changing this resets those edits.

Each file can be one row per sample, or an 8×12 grid of wells. In either case the tool finds iNat observation numbers or observation URLs.

2Review & look up samples

iNat obsPlateWellFileiNat status
A plain lookup table of every sample, plate and well, for your records.

3Connect to iNaturalist

Sign in to iNaturalist and open inaturalist.org/users/api_token. Copy the long api_token value and paste it here. The token lasts 24 hours. It stays in this page's memory, is sent only to iNaturalist, and is not saved anywhere.

Observation field to write to

If no suitable field exists, create one on iNaturalist (for example, “Mycota Lab Plate” with datatype text), then search for it here. Choose text so labels like “2026 #1” work, and so a sample sent on two plates can hold “12, 15”.

4Check, then write

The check reads each observation and doesn't change anything. It shows which observations are new, which already have this plate, which have a different value, and which can't be found.

Writes go out one per second, to stay within iNaturalist's API rate guidance. A full plate of 96 takes about 2 minutes.
